# 单词连连看

一款用 PyQt5 写的英语单词配对记忆游戏，闯 10 关递进难度，配背景音乐和音效。

## 目录结构

```
word_link_game/
├── word_link_game.py          # 主程序
├── requirements.txt           # 依赖
├── build.bat                  # Windows 一键打包
├── data/
│   ├── words_default.txt      # 默认词库（七年级下册）
│   └── words_custom.txt       # 用户上传的词库（覆盖默认）
└── sounds/                    # 运行时会自动生成（音效 / 背景音乐）
    ├── correct.wav
    ├── wrong.wav
    ├── click.wav
    ├── win.wav
    └── bgm.wav
```

## 玩法

- 鼠标点一张英文卡，再点对应中文卡
- **配对成功：两卡会闪一下后缩小 + 淡出消失**（带音效 + 加分 +10）
- 配对错误播放"咚"音效并扣分（-2）
- **每关固定 10 对单词（共 20 张卡，5×4 网格）**
- **每关都限时**，根据关卡递增难度：
  - L1 = 120s，L2 = 110s，L3 = 100s，L4 = 90s，L5 = 80s
  - L6 = 72s，L7 = 65s，L8 = 58s，L9 = 52s，L10 = 45s
- 倒计时结束未配对完成 → 挑战失败，可选「重新挑战本关」或「从第 1 关再来」

## 上传词库

主界面点 **📁 上传单词表**，选 `.txt` 文件即可。

支持的两种格式：

1. `英文 | 中文 | 例句`（管道符分隔）
2. JS 字面量：`{ word: "fox", meaning: "狐狸", sentence: "...", unit: "七下Unit1" }`

## 快捷键

- `M`：静音 / 取消静音背景音乐
- `Esc`：退出

## 打包 EXE

直接双击 `build.bat`，产物在 `dist/单词连连看.exe`。
